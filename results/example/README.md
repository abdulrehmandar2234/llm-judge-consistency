# ⚠️ Simulated output — not a measurement

**Nothing in this directory is an experimental result.** No model was called to
produce any of it.

The files here were generated by [`simulate.py`](simulate.py), which fabricates
rankings by applying a fixed number of adjacent swaps to an arbitrary reference
order. The resulting "agreement" figures are arithmetic on noise chosen by hand
— they describe the swap counts in that script and nothing else. The `model`
field in every record reads `SIMULATED-no-model-was-called`.

## Then why is it here

So the analysis pipeline can be read without an API key and without spending
anything. Everything in this directory came out of the **real** `evaluate.py`
and `plots.py`, unmodified — only the input was invented. It shows the shape of
the output: what the summary table reports, what the three charts look like,
what `metrics.json` contains.

It is the plumbing on display, not a finding.

## Files

| File | What it is |

| `runs.jsonl` | 60 invented records, each flagged `"SIMULATED": true` |
| `summary.md` | Real `evaluate.py` output over invented input, with a banner |
| `metrics.json` | Same, the full numbers |
| `agreement.png` | Real `plots.py` output over invented input |
| `position_bias.png` | Same |
| `rank_spread.png` | Same |

## The one trap to avoid

The swap counts in `simulate.py` were ordered so the output *roughly resembles*
the predictions in the repository README (order affecting the ranking more than
temperature, top-5 overlap lagging tau).

**That resemblance is circular and proves nothing.** I chose those numbers after
writing the predictions. Treating this output as support for them would be
exactly the error the repository is about. The predictions can only be tested by
running the real sweep.

## Getting real results

```bash
cp .env.example .env        # add OPENAI_API_KEY
python src/rank.py          # 60 real API calls
python src/evaluate.py
python src/plots.py
```

Those write to `results/`, one level up. This directory stays as it is.
